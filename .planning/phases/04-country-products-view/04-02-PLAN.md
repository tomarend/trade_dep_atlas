Add a new callback that reads from the data store and weight sliders, recalculates composite scores, and outputs to the AG Grid:

```python
@callback(
    Output("product-table", "rowData"),
    [Input("country-data-store", "data"),
     Input("weight-hhi", "value"),
     Input("weight-geo", "value"),
     Input("weight-ess", "value")],
)
def update_product_table(products, w_hhi, w_geo, w_ess):
    """Recalculate composite scores with current weights and update AG Grid."""
    if not products:
        return []
    for p in products:
        p["weighted_composite"] = round(
            w_hhi * p["hhi"] + w_geo * p["basket_geo_risk"] + w_ess * p["essentiality_score"],
            4,
        )
    # Sort by weighted composite descending
    products.sort(key=lambda x: x["weighted_composite"], reverse=True)
    return products
```

This callback fires when:
1. Country changes → new data loads into store → table re-renders
2. Weight slider changes → same data, new composite → table re-sorts

The debounce is handled naturally by Dash's callback batching and the clientside weight adjustment. The 300-500ms debounce from CONTEXT.md is achieved by Dash's built-in input debounce behavior. If needed, add `debounce=True` to the slider components (go back and add `updatemode="drag"` to each dcc.Slider if not already set — this ensures sliders update during drag for responsive feel).
