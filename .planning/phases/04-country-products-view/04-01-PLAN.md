1. `get_product_scores(importer_iso3: str, year: int | None = None) -> list[dict]`:
   - If `_conn is None`: return empty list
   - Default year: `year or get_year_range()[1]`
   - SQL query:
     ```sql
     SELECT DISTINCT
         ds.hs6,
         COALESCE(p.description, '') AS description,
         ds.essentiality_tier,
         ds.hhi,
         ds.basket_geo_risk,
         ds.essentiality_score,
         ds.composite_score
     FROM dependency_scores ds
     LEFT JOIN products p ON ds.hs6 = p.hs6
     WHERE ds.importer_iso3 = ? AND ds.year = ?
     ORDER BY ds.composite_score DESC
     ```
   - Parameters: `[importer_iso3, yr]`
   - Return list of dicts with keys: `hs6`, `description`, `essentiality_tier`, `hhi`, `basket_geo_risk`, `essentiality_score`, `composite_score`
   - Round float values to 4 decimal places

2. `get_country_summary(importer_iso3: str, year: int | None = None) -> dict`:
   - If `_conn is None`: return dict with all zeros
   - Default year: `year or get_year_range()[1]`
   - SQL query (subquery to get one row per product first):
     ```sql
     SELECT
         AVG(hhi) AS avg_hhi,
         AVG(basket_geo_risk) AS avg_geo_risk,
         AVG(essentiality_score) AS avg_essentiality,
         AVG(composite_score) AS avg_composite,
         COUNT(*) AS product_count,
         SUM(CASE WHEN essentiality_tier = 'critical' THEN 1 ELSE 0 END) AS critical_count,
         SUM(CASE WHEN composite_score > 0.7 THEN 1 ELSE 0 END) AS high_risk_count
     FROM (
         SELECT DISTINCT hs6, hhi, basket_geo_risk, essentiality_score,
                essentiality_tier, composite_score
         FROM dependency_scores
         WHERE importer_iso3 = ? AND year = ?
     ) sub
     ```
   - Return dict: `{"avg_hhi", "avg_geo_risk", "avg_essentiality", "avg_composite", "product_count", "critical_count", "high_risk_count"}`
   - Round avg values to 3 decimal places

3. `get_supplier_breakdown(importer_iso3: str, hs6: str, year: int | None = None) -> list[dict]`:
   - If `_conn is None`: return empty list
   - Default year: `year or get_year_range()[1]`
   - SQL query:
     ```sql
     SELECT
         ds.exporter_iso3,
         COALESCE(c.name, ds.exporter_iso3) AS exporter_name,
         ds.supplier_share,
         ds.value_usd,
         ds.exporter_geo_risk,
         c.region,
         c.continent
     FROM dependency_scores ds
     LEFT JOIN countries c ON ds.exporter_iso3 = c.iso3
     WHERE ds.importer_iso3 = ? AND ds.hs6 = ? AND ds.year = ?
     ORDER BY ds.supplier_share DESC
     ```

   - Return list of dicts with keys: `exporter_iso3`, `exporter_name`, `supplier_share`, `value_usd`, `exporter_geo_risk`, `region`, `continent`
   - Round supplier_share and exporter_geo_risk to 4 decimal places

All functions follow the existing guard pattern: check `if _conn is None` first, wrap in try/except with `logger.error`, return empty default on failure. Do NOT add lru_cache to these (they have varying parameters).

2. **Proportional weight adjustment** (clientside callback for instant feel):
   When any slider changes, adjust the other two proportionally so all three sum to 1.0. Use `clientside_callback` with JS:
   ```python
   clientside_callback(
       """
       function(hhi, geo, ess, triggered) {
           const sum = hhi + geo + ess;
           if (Math.abs(sum - 1.0) < 0.001) return window.dash_clientside.no_update;
           const tid = window.dash_clientside.callback_context.triggered_id;
           if (tid === 'weight-hhi') {
               const remainder = 1.0 - hhi;
               const otherSum = geo + ess;
               if (otherSum > 0) {
                   return [hhi, remainder * geo / otherSum, remainder * ess / otherSum];
               }
               return [hhi, remainder / 2, remainder / 2];
           } else if (tid === 'weight-geo') {
               const remainder = 1.0 - geo;
               const otherSum = hhi + ess;
               if (otherSum > 0) {
                   return [remainder * hhi / otherSum, geo, remainder * ess / otherSum];
               }
               return [remainder / 2, geo, remainder / 2];
           } else {
               const remainder = 1.0 - ess;
               const otherSum = hhi + geo;
               if (otherSum > 0) {
                   return [remainder * hhi / otherSum, remainder * geo / otherSum, ess];
               }
               return [remainder / 2, remainder / 2, ess];
           }
       }
       """,
       [Output("weight-hhi", "value"), Output("weight-geo", "value"), Output("weight-ess", "value")],
       [Input("weight-hhi", "value"), Input("weight-geo", "value"), Input("weight-ess", "value")],
       prevent_initial_call=True,
   )
   ```

3. **Load product data on country change:**

4. **Update summary cards from stored data + weights:**
   ```python
   @callback(
       Output("country-summary-cards", "children"),
       [Input("country-data-store", "data"),
        Input("weight-hhi", "value"),
        Input("weight-geo", "value"),
        Input("weight-ess", "value")],
   )
   def update_summary_cards(products, w_hhi, w_geo, w_ess):
       if not products:
           return html.Div("Select a country to view exposure analysis.", className="text-muted p-3")
       # Recalculate composite scores with current weights
       for p in products:
           p["weighted_composite"] = (
               w_hhi * p["hhi"] + w_geo * p["basket_geo_risk"] + w_ess * p["essentiality_score"]
           )
       avg_composite = sum(p["weighted_composite"] for p in products) / len(products)
       avg_hhi = sum(p["hhi"] for p in products) / len(products)
       avg_geo = sum(p["basket_geo_risk"] for p in products) / len(products)
       avg_ess = sum(p["essentiality_score"] for p in products) / len(products)
       critical_count = sum(1 for p in products if p["essentiality_tier"] == "critical")
       high_risk = sum(1 for p in products if p["weighted_composite"] > 0.7)

       level = "high" if avg_composite > 0.7 else "medium" if avg_composite > 0.4 else "low"

       return dbc.Row([
           dbc.Col(dbc.Card(dbc.CardBody([
               html.P("Overall Exposure", className="text-muted mb-1 small fw-semibold"),
               html.H2(f"{avg_composite:.3f}", className=f"mb-0 score-value score-{level}"),
               html.Span(f"{len(products)} products · {high_risk} high-risk", className="text-muted small"),
           ])), md=3),
           dbc.Col(dbc.Card(dbc.CardBody([
               html.P("Concentration (HHI)", className="text-muted mb-1 small fw-semibold"),
               html.H3(f"{avg_hhi:.3f}", className="mb-0"),
           ])), md=3),
           dbc.Col(dbc.Card(dbc.CardBody([
               html.P("Geo Risk", className="text-muted mb-1 small fw-semibold"),
               html.H3(f"{avg_geo:.3f}", className="mb-0"),
           ])), md=3),
           dbc.Col(dbc.Card(dbc.CardBody([
               html.P("Essentiality", className="text-muted mb-1 small fw-semibold"),
               html.H3(f"{avg_ess:.3f}", className="mb-0"),
               html.Span(f"{critical_count} critical", className="text-muted small"),
           ])), md=3),
       ], className="g-3")
   ```
