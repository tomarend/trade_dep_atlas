**Tab 1 — HHI Concentration** (`tab-hhi`):
Content sections:
- Formula: `dcc.Markdown("### Formula\\n\\n$$HHI = \\\\sum_{i=1}^{n} s_i^2$$\\n\\nwhere $s_i$ is supplier $i$'s share of import value for the product-importer pair.", mathjax=True)`
- Interpretation: values range 0–1 after normalization (raw HHI is 0–10,000 when shares in %; here we use shares as fractions 0–1 so raw range is already 0–1)
- Normalization note: HHI of 1.0 = complete monopoly (single supplier), HHI near 0 = many equally-sized suppliers
- Why HHI over alternatives: short paragraph — HHI is sensitive to the largest suppliers (quadratic weighting), captures tail risk better than simple supplier count, and is widely used in competition policy

**Tab 2 — Geopolitical Risk** (`tab-georisk`):
Content sections:
- WGI 6 dimensions (use a `dbc.Table` or `dbc.ListGroup`): Voice & Accountability, Political Stability & Absence of Violence, Government Effectiveness, Regulatory Quality, Rule of Law, Control of Corruption
- Coverage gaps note: Freedom House scores used as fallback for territories without WGI coverage (Taiwan, Kosovo, Palestine)
- Sanctions multiplier: GSDB (Global Sanctions Database, Drexel/Stanford) — formula block:
  `dcc.Markdown("$$geo\\_risk = governance\\_risk \\\\times (1 + sanctions\\_intensity)$$", mathjax=True)`
- Composite note: governance_risk is normalized 0–1 (higher = worse governance), sanctions_intensity is total sanction events normalized 0–1

**Tab 3 — Essentiality** (`tab-essentiality`):
Content sections:
- Three-tier structure table (`dbc.Table`, striped=True):
  | Tier | Score Range | Examples |
  |------|-------------|---------|
  | Critical | 0.85–1.0 | Critical raw materials (EU CRM 2023), USGS critical minerals |
  | Important | 0.45–0.7 | Energy products, pharma, food staples, semiconductors |
  | Standard | 0.1–0.3 | General industrial inputs |
- Within-tier gradient note: a product's exact score within its tier is modulated by its global export HHI — a critical material with highly concentrated global supply scores at the top of the Critical range

Create `dashboard/pages/country.py`:

```python
import dash
from dash import html, dcc
import dash_bootstrap_components as dbc
from dashboard import data

dash.register_page(
    __name__,
    path="/country",
    name="Country Exposure",
    title="DependencyAtlas — Country Exposure",
)

def layout():
    default_country = data.get_default_country()
    return dbc.Container([
        dbc.Row([
            dbc.Col(html.H3("Country Exposure"), width=12),
        ], className="mb-3"),
        dbc.Row([
            dbc.Col([
                dcc.Loading(
                    id="loading-country-content",
                    type="circle",
                    children=html.Div(
                        id="country-content-placeholder",
                        children=dbc.Alert(
                            f"Country view coming in Phase 4. Default selection: {default_country}",
                            color="info",
                            className="mt-3",
                        ),
                        style={"minHeight": "400px"},
                    ),
                )
            ], width=12),
        ]),
    ], fluid=True, className="py-4")
```

Use `layout` as a **callable** (function returning layout) rather than a module-level variable — this is needed because `data.get_default_country()` should be called at request time (so it works even if data becomes available after module import).
