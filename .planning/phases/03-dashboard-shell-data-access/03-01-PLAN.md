dependency_scores fact table columns:
  importer_iso3, hs6, year, exporter_iso3, value_usd, supplier_share,

Running queries:

  <name>Task 1: Dashboard data access layer (dashboard/data.py)</name>
  <files>dashboard/__init__.py, dashboard/data.py</files>
  <action>
Create `dashboard/__init__.py` as an empty file (package marker).

Create `dashboard/data.py` implementing a module-level DuckDB singleton pattern:

1. **DB path resolution:** Read path from environment variable `DASHBOARD_DB` if set, otherwise default to `data/dashboard.duckdb` relative to the project root (resolved using `pathlib.Path(__file__).parent.parent / "data" / "dashboard.duckdb"`).

2. **Connection singleton:** At module level, attempt `duckdb.connect(str(db_path), read_only=True)`. If the file does not exist, set `_conn = None`. Store as a private module-level variable.

3. **Expose `db_available: bool`** at module level — `True` if conn opened successfully, `False` otherwise.

4. **Cached startup data** — use `functools.lru_cache(maxsize=1)` on each:
   - `get_year_range() -> tuple[int, int]`: executes `SELECT MIN(year), MAX(year) FROM dependency_scores` — returns `(1995, 2022)` as fallback if conn is None
   - `get_country_list() -> list[tuple[str, str]]`: executes `SELECT iso3, name FROM countries ORDER BY name` — returns `[]` fallback
   - `get_default_country() -> str`: executes `SELECT importer_iso3 FROM dependency_scores GROUP BY importer_iso3 ORDER BY AVG(composite_score) DESC LIMIT 1` — returns `"USA"` as fallback
   - `get_default_product() -> str`: executes `SELECT hs6 FROM dependency_scores GROUP BY hs6 ORDER BY AVG(composite_score) DESC LIMIT 1` — returns `"271019"` as fallback

5. All DB calls wrapped in try/except — on any DuckDB exception, log with loguru and return the fallback value.

Use `loguru` for all logging (already in dependencies). Log at startup: "DuckDB connected: {db_path}" or "DuckDB not found at {db_path} — running in offline mode".
