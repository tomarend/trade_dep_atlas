**data.py changes:**
1. Add `get_score_trend(importer_iso3: str, hs6: str) -> list[dict]` — returns time series for all years:
   ```sql
   SELECT DISTINCT year, composite_score, hhi, basket_geo_risk, essentiality_score
   FROM dependency_scores
   WHERE importer_iso3 = ? AND hs6 = ?
   ORDER BY year
   ```
   Returns list of dicts with keys: year, composite_score, hhi, basket_geo_risk, essentiality_score.
   Uses same pattern as other parameterized queries (guard on `_conn is None`, try/except, logger.error).

2. Add `get_trade_flows(hs6: str, year: int | None = None) -> list[dict]` — returns exporter→importer flows for Sankey/network:
   ```sql
   SELECT
       ds.exporter_iso3,
       COALESCE(ce.name, ds.exporter_iso3) AS exporter_name,
       ds.importer_iso3,
       COALESCE(ci.name, ds.importer_iso3) AS importer_name,
       ds.value_usd,
       ds.supplier_share,
       ds.exporter_geo_risk
   FROM dependency_scores ds
   LEFT JOIN countries ce ON ds.exporter_iso3 = ce.iso3
   LEFT JOIN countries ci ON ds.importer_iso3 = ci.iso3
   WHERE ds.hs6 = ? AND ds.year = ?
   ORDER BY ds.value_usd DESC
   ```
   Returns list of dicts. Uses same guard pattern.
