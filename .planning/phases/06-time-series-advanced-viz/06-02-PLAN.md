   ```python
        Input("year-store", "data")],
   )
   def update_product_trend(hs6, year):
   ```
   This callback queries trend data. Since this is product-level (not per-importer), we need a slightly different approach: pick a representative importer or compute aggregated stats. The simplest correct approach: use the data that's already available — `get_score_trend` takes an importer, so instead we query aggregated product data across years.

   **Approach:** Add a new query function `get_product_trend(hs6: str) -> list[dict]` to data.py that returns per-year aggregated stats:
   ```sql
   SELECT year,
          AVG(composite_score) AS composite_score,
          AVG(hhi) AS hhi,
          AVG(basket_geo_risk) AS basket_geo_risk,
          AVG(essentiality_score) AS essentiality_score
   FROM (
       SELECT DISTINCT importer_iso3, year, composite_score, hhi, basket_geo_risk, essentiality_score
       FROM dependency_scores
       WHERE hs6 = ?
   ) sub
   GROUP BY year
   ORDER BY year
   ```
   Add this to `dashboard/data.py` with the same guard pattern as other queries.
