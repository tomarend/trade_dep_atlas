  <behavior>
    - ingest_baci_year(csv_path, country_mapping, concordance_map, descriptions) returns a Polars DataFrame with enriched columns
    - Input CSV columns: t, i, j, k, v, q
    - Output DataFrame columns: year, exporter_baci, importer_baci, exporter_iso3, importer_iso3, hs6_original, concorded_hs6, hs2, hs4, product_description, category, concordance_flag, value_usd, quantity_kg, unit_value, outlier_flag
    - Rows with null value (v) are dropped; rows with v=0 are kept
    - Unit value = v / q (null if q is 0 or null)
    - Outlier flag set for values > 3σ from product-level mean within that year
    - run_ingestion(config) processes all CSVs in raw_dir, writes Parquet to processed_dir partitioned by year
    - Already-processed years are skipped if processed Parquet exists and raw CSV is unchanged
  </behavior>
  <action>
1. Create `pipeline/ingest.py`:
   - `def ingest_baci_year(csv_path: Path, country_mapping: dict[int, "CountryRecord"], concordance_map: dict[str, str], descriptions: dict[str, tuple[str, str]]) -> pl.DataFrame`:
     - Use `pl.scan_csv(csv_path)` for lazy evaluation (low memory)
     - Rename columns: t→year, i→exporter_baci, j→importer_baci, k→hs6_original, v→value_usd, q→quantity_kg
     - Cast hs6_original to string (str), zero-pad to 6 digits: `.cast(pl.Utf8).str.zfill(6)`
     - Filter: drop rows where value_usd is null. Keep rows where value_usd == 0.
     - Map exporter_baci → exporter_iso3 using country_mapping dict. Use `pl.col("exporter_baci").map_elements(lambda x: country_mapping.get(x, _UNKNOWN).iso3, return_dtype=pl.Utf8)`. Create a sentinel `_UNKNOWN = CountryRecord(baci_code=0, iso3="UNK", ...)` for unmapped codes.
     - Same for importer_baci → importer_iso3
     - Map hs6_original → concorded_hs6 using concordance_map dict via `pl.col("hs6_original").replace(concordance_map)` (Polars replace is vectorized). If code not in map, keep original.
     - Derive hs2 = concorded_hs6[:2], hs4 = concorded_hs6[:4] using `pl.col("concorded_hs6").str.slice(0, 2)` and `.str.slice(0, 4)`
     - Map concorded_hs6 → (description, category) using descriptions dict. Use map_elements for description, map_elements for category.
     - Add concordance_flag: "mapped" if hs6_original != concorded_hs6, "unchanged" if equal. (Finer-grained flags come from the concordance module but for the Polars path, binary is sufficient.)
     - Compute unit_value: `pl.when(pl.col("quantity_kg") > 0).then(pl.col("value_usd") / pl.col("quantity_kg")).otherwise(None)`
     - Compute outlier_flag: group by (concorded_hs6), compute mean and std of value_usd, flag rows where value_usd > mean + 3*std. Use `.over("concorded_hs6")` window function.
     - `.collect()` at the end to materialize
     - Return the DataFrame

   - `def run_ingestion(config: dict) -> dict`:
     - Read paths from config: raw_dir, processed_dir, reference_dir
     - Load country_mapping via `load_country_mapping(Path(reference_dir))`
     - Load concordance via `load_concordance(Path(reference_dir))`, then `build_concordance_polars_map(concordance)`
     - Load descriptions via `load_product_descriptions(Path(reference_dir))`
     - List all CSV files in raw_dir matching pattern `BACI_*.csv` or `*.csv`
     - For each CSV file:
       - Extract year from filename or from first row's `t` column
       - Check if `processed_dir/year={year}/` exists — if so, check if raw CSV is newer than Parquet (by mtime). Skip if Parquet is up-to-date.
       - Call `ingest_baci_year(csv_path, country_mapping, concordance_map, descriptions)`
       - Write result as Parquet to `processed_dir/year={year}/data.parquet` using `df.write_parquet(path, compression="zstd")`
       - Log with loguru: year, row count, time taken
     - Return summary dict: `{"years_processed": [...], "years_skipped": [...], "total_rows": N, "duration_seconds": T}`

     ```json

         "failed": 0

       "concordance_warnings": []
     }
     ```
     Return manifest path.

   - `def main(config_path: Path | None = None, skip_download: bool = False) -> None`:
     Full pipeline orchestration:
     1. Load config from pipeline.yaml (or config_path if provided)
     2. Create output directories if not exist: raw_dir, processed_dir, reference_dir
     3. Log pipeline start with loguru: "Pipeline starting..."
     4. **Stage 1: Download** (skip if skip_download=True)

     6. **Stage 3: Ingest**
        - Call `run_ingestion(config)` → get summary dict
        - Log: "{N} years processed, {R} total rows"
     7. **Stage 4: Write manifest**
        - Combine download report + ingestion summary + concordance warnings
        - Call `write_manifest(processed_dir, combined_report)`
        - Log: "Manifest written to {path}"
     8. Log pipeline completion: "Pipeline complete in {duration}s"
