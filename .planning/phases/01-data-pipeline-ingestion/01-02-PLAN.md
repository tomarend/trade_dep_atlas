2. Create `pipeline/concordance.py`:
   - `@dataclass ConcordedProduct`: fields `original_hs6: str`, `concorded_hs6: str`, `hs2: str`, `hs4: str`, `description: str`, `category: str`, `concordance_flag: str` (values: "unchanged", "mapped", "split", "merged", "unmapped")
   - `@dataclass Concordance`: fields `forward_map: dict[str, list[str]]` (source_hs6 → list of target_hs6), `reverse_map: dict[str, list[str]]` (target_hs6 → list of source_hs6), `descriptions: dict[str, tuple[str, str]]` (hs6 → (description, category)), `source_revision: str`, `target_revision: str`

   - `def load_product_descriptions(reference_dir: Path) -> dict[str, tuple[str, str]]`:
     Read `hs_product_descriptions.csv`. Return dict mapping hs6 → (description, category).

   - `def load_concordance(reference_dir: Path, source_revision: str = "H4", target_revision: str = "H6") -> Concordance`:
     - Look for WITS concordance CSV files in `reference_dir / "concordance/"` with naming pattern like `JobID-*.csv` or `hs{source}_to_hs{target}.csv`
     - If concordance files exist: parse them to build forward_map and reverse_map
     - If concordance files do not exist: log warning, create an identity mapping (code maps to itself) — this lets the pipeline run without concordance tables for development/testing
     - Load product descriptions
     - Return Concordance object

   - `def apply_concordance(hs6_code: str, concordance: Concordance) -> ConcordedProduct`:
     - Lookup hs6_code in forward_map
     - If not found: return ConcordedProduct with concorded_hs6=hs6_code, flag="unmapped" (identity — keep original)
     - If maps to exactly 1 target: flag="mapped" (or "unchanged" if same code)
     - If maps to multiple targets (one-to-many split): use the first target alphabetically, flag="split"
     - For many-to-one (detected via reverse_map): flag="merged"
     - Set hs2 = concorded_hs6[:2], hs4 = concorded_hs6[:4]
     - Look up description from concordance.descriptions, default to "Unknown product"
     - Return ConcordedProduct

   - `def build_concordance_polars_map(concordance: Concordance) -> dict[str, str]`:
     Build a flat dict mapping every known source HS6 → single target HS6. This is used by the ingestion pipeline for vectorized Polars `map_elements` or `replace` operations. For one-to-many splits, pick the first target (same rule as apply_concordance).

   - `def validate_concordance(concordance: Concordance) -> list[str]`:
     Return list of warning messages:
     - Count of unmapped codes (codes in descriptions but not in forward_map)
     - Count of one-to-many splits
     - Count of many-to-one merges
     - Spot check: verify known critical products exist in mapping (list: "280461" lithium, "260300" copper, "854231" semiconductors)
