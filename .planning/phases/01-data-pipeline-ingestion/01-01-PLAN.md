  <behavior>
    - download_baci(config, output_dir) downloads BACI CSV files to output_dir
    - Already-existing files in output_dir are skipped (not re-downloaded)
    - Failed HTTP requests are retried up to config["baci"]["retry_count"] times with exponential backoff
    - After max retries, failed files are skipped and reported (not raised)
    - ZIP files are extracted after download, CSV extracted into output_dir
    - Returns a DownloadReport with lists of downloaded, skipped, and failed files
    - Verifies each downloaded CSV has expected BACI columns: t, i, j, k, v, q
  </behavior>
  <action>
1. Create `pipeline/download.py`:
   - `@dataclass DownloadReport`: fields `downloaded: list[Path]`, `skipped: list[Path]`, `failed: list[tuple[str, str]]` (url, error message)
   - `def discover_baci_urls(download_page_url: str) -> list[dict]`: Fetch the BACI download page HTML, parse it to find all CSV/ZIP download links. Return list of dicts with keys `url`, `filename`, `hs_revision`. Use a simple regex or string search for href patterns matching BACI data files (pattern: `BACI_HS[0-9]+_V[0-9]+`). If page fetch fails, fall back to a hardcoded list of known BACI URL patterns.
   - `def download_file(url: str, dest: Path, chunk_size: int = 65536, timeout: int = 300) -> Path`: Stream download with `requests.get(url, stream=True, timeout=timeout)`. Write in chunks to dest. Return dest path. Raise on HTTP error.
   - `def extract_zip(zip_path: Path, output_dir: Path) -> list[Path]`: Extract ZIP contents to output_dir using `zipfile.ZipFile`. Return list of extracted file paths. Delete ZIP after successful extraction.
   - `def verify_baci_csv(csv_path: Path) -> bool`: Read first line of CSV, check it contains expected columns `t,i,j,k,v,q` (case-insensitive, stripped). Return True/False.
   - `def download_baci(config: dict, output_dir: Path | None = None) -> DownloadReport`: Main entry point.
     - Read settings from config dict (keys: `baci.download_page`, `baci.raw_dir`, `baci.retry_count`, `baci.retry_backoff_seconds`, `baci.chunk_size_bytes`, `baci.request_timeout_seconds`)
     - output_dir defaults to `Path(config["baci"]["raw_dir"])`
     - Create output_dir if not exists
     - Call `discover_baci_urls` to get file list
     - For each file: if CSV already exists in output_dir, add to skipped list and continue
     - Otherwise: attempt download with retry loop (retry_count times, backoff = retry_backoff_seconds * 2^attempt)
     - Show tqdm progress bar per file (total=content-length if available)
     - After download: if ZIP, extract; verify CSV columns
     - If verification fails, log warning and add to failed list
     - Log progress with loguru: which file is downloading, success/skip/fail
     - Return DownloadReport
